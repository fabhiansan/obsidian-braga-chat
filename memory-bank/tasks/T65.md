## Context

### Scoring Formulas
- **Staged → Core**: `0.5×newness + 0.3×importance + 0.2×frequency`
  - newness = exp(-ageDays / 7)
  - importance = (contentLength/500 + tagCount/5) / 2
  - frequency = log1p(accessCount) / log1p(10)
- **Core Retention**: `0.4×recency + 0.4×importance + 0.2×frequency`
  - recency = exp(-daysSinceAccess / 30)

### File Structure
- `intelligence/core.json` — Hot memories (injected into system prompt)
- `intelligence/staged.json` — New memories awaiting evaluation
- `intelligence/archive.json` — Long-term storage, search-only
- `intelligence/memory-audit.jsonl` — Audit log (shared with legacy)

### Architecture
`ThreeTierMemoryStore` class provides:
- `create()` — Always writes to staged
- `read()` — Searches all tiers, increments access count
- `evaluateStaged()` — Promotes high-scorers, demotes lowest if core full
- `cullCore()` — Demotes entries below archive threshold
- `getSystemPromptContext(maxTokens?)` — Formats core for system prompt
- `migrateFromLegacy()` — One-time migration from flat memory.json
