# T58: Integrate Sync UI into Chat Lab

*Created: 2026-08-20*
*Status: 🔄 IN PROGRESS*
*Last Updated: 2026-08-23 01:27:43 IST*
*Parent: T42 (Remote Chat Storage & Sync)*
*Scope: UI/UX Redesign — Move sync from separate sidebar into Chat Lab*
*Migration: Canonical replacement for the sync records previously stored under T43.*

## Objective

Replace the standalone sync sidebar (`SyncSidebarView`) with an integrated sync experience inside the Chat Lab sidebar. Sync is a first-class tab alongside chat sessions; the original export-dropdown entry point has since moved to a direct Sync toolbar button.

## Background

Commit `eebcfb6` (T42f) introduced a separate `SYNC_SIDEBAR_VIEW_TYPE` sidebar for sync progress. This creates two sidebar views for one plugin, which is poor UX. The sync UI also lacks the rich display patterns proven in SyncIt (per-file log entries, progress cards, mode selector).

**T42f is superseded by this task.** The existing `SyncSidebarView.ts` code will be removed; its patterns will be ported into a new `ChatSyncPanel` component rendered inside chat tabs.

## Acceptance Criteria

- [x] **Remove 2nd sidebar**: `SYNC_SIDEBAR_VIEW_TYPE` registration, `activateSyncSidebar()`, ribbon icon, related commands deleted
- [x] **Export dropdown**: ActionBar export button opens dropdown with "Export" and "Sync" options
- [x] **Sync tab**: Clicking "Sync" opens a special non-session tab in `ChatTabBar` (label: "🔄 Sync")

- [x] **Completion summary**: Cards showing sync results with icons and colors
- [x] **Cancel**: Working cancel button during active sync
- [x] **Debug logging**: All sync operations logged via existing `FileLogger` (no separate log tab)
- [x] **Settings access**: Sync settings remain in main Settings panel (no change needed)

## Architecture

### Component Hierarchy

```
ChatApp
├── ChatToolbar (ActionBar)
│   └── ExportDropdown → opens menu with Export / Sync
├── ChatTabBar
│   ├── Session tabs (existing)
│   └── 🔄 Sync tab (new, special non-session tab)
└── ChatMainArea
    ├── Regular session content (existing)
    └── ChatSyncPanel (new, when sync tab active)
        ├── Direction selector
        ├── Dry run toggle
        ├── Status display
        ├── Progress bar + stats
        ├── Per-session log list
        └── Action buttons (Sync, Cancel)
```

### State Flow

```
User clicks Export dropdown → "Sync"
  → openSyncTab() adds "__sync__" to openSessionIds, sets activeSessionId = "__sync__"
  → ChatMainArea detects sync tab → renders ChatSyncPanel instead of ChatMessages
  → ChatSyncPanel calls plugin.triggerSync(direction, dryRun) when user clicks Sync
  → SyncEngine runs with given direction
  → Progress callbacks update ChatSyncPanel state
  → Results displayed as completion cards
```

## Implementation Phases

### Phase 1: Remove 2nd Sidebar ✅
- Delete `SYNC_SIDEBAR_VIEW_TYPE` registration from `main.ts`
- Delete `activateSyncSidebar()`, `getSyncSidebarView()`, `registerView` for sync sidebar
- Delete sync ribbon icon and "Open Chat Sync" command
- Remove `src/ui/SyncSidebarView.ts` (or deprecate)

### Phase 2: Add Settings Default ✅
- Add `syncDirection: "both" | "upload" | "download"` to `RemoteStorageConfig`
- Add to `DEFAULT_SETTINGS`, `normalizeSettings`
- Add direction selector to sync settings section

### Phase 3: Export Dropdown + Sync Tab ✅
- Create `ExportDropdown.tsx` component
- Modify `ActionBar.tsx` to use dropdown instead of direct export button
- Add `openSyncTab()` / `closeSyncTab()` to `useSessionActions`
- Modify `ChatTabBar` to render "🔄 Sync" tab for `__sync__` ID
- Handle tab close for sync tab

### Phase 4: ChatSyncPanel ✅
- Create `ChatSyncPanel.tsx` with:
  - Direction selector dropdown (reads default from settings)
  - Dry run toggle
  - Status area (idle / syncing / complete / error)
  - Progress bar + stat counters
  - Per-session log list (scrollable)
  - Sync / Cancel / Settings buttons
- Port rich UI patterns from SyncIt:
  - Color-coded badges for operations
  - Completion summary cards
  - File-size formatting

### Phase 5: SyncEngine Direction Control ✅
- Modify `SyncEngine.sync(direction?)` to accept optional direction override
- Filter `computeSyncPlan()` results based on direction
- Ensure dry-run respects direction

### Phase 6: Integration & Testing ✅
- Wire `ChatApp` to render `ChatSyncPanel` when sync tab active
- Test sync flow end-to-end
- Verify debug logging works
- Build and test in Obsidian
