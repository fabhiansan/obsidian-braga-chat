## Description
Add a bounded, read-only tool that lets the agent run Dataview Query Language
(DQL) against the vault when the Dataview plugin exposes its public query API.
This is a narrow T17 capability. It does not complete T17's other vault-tool
phases or T26 Phase 4's planned Dataview provider under the T39 Integration
Provider API.

## Acceptance Criteria
- [x] Register `query_dataview` only when Dataview's public query API is available.
- [x] Support DQL through `tryQueryMarkdown` or the compatible `queryMarkdown` result API.
- [x] Bound input to 5,000 characters and formatted output to 12,000 characters (8,000 by default).
- [x] Use the shared built-in tool registry and executor for native and OpenResponses calls.
- [x] Do not execute DataviewJS.
- [ ] Verify behavior in a live Obsidian vault with Dataview installed.

## Implementation Details
The optional handler returns a readable query result or a structured error.
It is unavailable when Dataview is absent or its supported public query API is
not present. The capability is not a T39 integration provider; migrating
Dataview to that provider contract remains separate future work.
